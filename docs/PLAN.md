# 星穹塔罗 · v1.3.7 优化计划

> 建立：2026-11-18 ｜ 基线：v1.3.6（线上同版）｜ 目标：v1.3.7
> 关联记录：`CHANGELOG.md`、`docs/DEV_LOG.md`

## 1. 背景

线上版本已到 v1.3.6（左右翻牌、魔力源声明、3D 场景重做、首屏按需加载均已完成）。
用户当前诉求只剩一项：**3D 牌桌观感仍偏"廉价"**，需要优化，且**不能拖慢加载**。

## 2. 目标

1. 提升 3D 牌桌质感：桌面更"实"、金饰有反射、符文更锐利、卡背更有细节。
2. **零新增网络请求**、零新增 Three.js addon、不启用后期处理（Bloom/SSAO 等）。
3. 首屏字节不增加（3D 模块本来就是按需加载）。
4. 完成版本管理：v1.3.7 提交 + tag + 推送 + 部署 + 日志。

## 3. 现状诊断（基于 v1.3.6 截图与代码）

| 问题 | 根因 |
|---|---|
| 桌面发灰、发雾，像一块"牛奶紫圆盘" | `glowDisc`（加法混合、opacity 0.9、半径 2.6R）+ 魔法阵加法混合，两层大面积叠加把桌面提亮成雾 |
| 金环像塑料 | 没有环境反射，金属度再高也只能反射黑色背景 |
| 魔法阵线条发虚 | 加法混合 + shadowBlur，让线条边缘糊开；旋转时更明显 |
| 星空有方块感 | `PointsMaterial` 默认方形点精灵 |
| 卡背偏黑，细节看不清 | 卡背自发光仅 0.28，主光角度偏上，牌背处于暗部 |
| 桌面缺乏微观纹理 | 512² 贴图 + 少量金屑，近景像纯色 |

## 4. 方案（全部程序化，零下载）

1. **环境反射**：512×256 Canvas 等距柱状渐变（深紫天幕 + 暖金地平光 + 冷色光斑）
   → `PMREMGenerator.fromEquirectangular` → `scene.environment`。
   金饰 `envMapIntensity ≈ 1.2`、桌面 0.35、卡牌 0.25~0.6，避免卡面被反射洗白。
2. **桌面**：贴图升至 1024²，增加细密噪点、24 道极淡放射纹与外缘暗角；
   `anisotropy = 8`，近景不再糊。
3. **魔法阵**：材质由 `AdditiveBlending` 改为 `NormalBlending`（线条锐利、不泛白），
   呼吸区间收敛到 0.80~0.94；光晕圆盘半径 2.6R → 2.2R、透明度 0.9 → 0.42。
4. **金饰**：口沿环与内刻环提高 `envMapIntensity`，金属度对齐真实金（≈0.9）。
5. **星空**：改用 64² 径向渐变点精灵贴图，消除方块感（1 张贴图，520 个点不变）。
6. **卡背**：自发光 0.28 → 0.40，金属度 0.06 → 0.12，边框金线在暗部仍可辨认。
7. **灯光**：保留克制主光（避免 Rider-Waite 暖白卡面过曝），追加一盏低强度暖金轮廓光，
   让桌沿与卡牌顶部有明确的边缘高光。

## 5. 性能预算

| 项目 | 预算 | 说明 |
|---|---|---|
| 新增网络请求 | 0 | 全部 Canvas 程序化生成 |
| 新增 JS 模块 | 0 | PMREMGenerator 属 three 核心 |
| 新增 draw calls | 0 | 不新增 Mesh，仅替换材质/贴图 |
| GPU 纹理增量 | ≈ +4.5 MB | 桌面 512²→1024²（+3MB）、环境 PMREM（≈1MB）、星点 64² |
| 单帧额外开销 | 可忽略 | 环境反射仅在初始化时预过滤一次 |
| 首屏字节 | 0 变化 | table3d.js 仍按需加载 |

### 执行补充
- 台面厚度由 0.34 增加到 0.62 并追加底沿金箍：仅改几何参数、+1 个 draw call，
  解决"扁平飞盘"感（原计划未列出，属执行期新增）。
- 相机距离按牌阵铺开半径在 0.88×~1.0× 之间平滑过渡：只改距离不改朝向，
  保持"固定视角"约定。

## 7. 风险与回退

| 风险 | 应对 |
|---|---|
| PMREM 在低端 GPU 初始化略慢 | 输入仅 512×256；try/catch 降级为无环境贴图 |
| 环境反射让卡面变灰 | 卡面 `envMapIntensity` 限定 ≤ 0.3 |
| 视觉不达预期 | 保留 v1.3.6 tag，可一键回退部署 |
